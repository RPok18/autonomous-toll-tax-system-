# ADR-003: ANPR acceptance threshold

- Status: Provisional baseline
- Date: 2026-10-23

## Context

Fusion accepts an ANPR signal when it contains a plate number and its
confidence is at least `anpr_min_confidence`. The default is 0.55. The current
Tesseract implementation emits heuristic scores of 0.85 for a
pattern-matching plate and 0.35 for a non-matching non-empty read, so the
default threshold currently rejects the latter.

The simulation harness includes S9, which sweeps thresholds from 0.55 through
0.85 in 0.05 increments for baseline and poor-visibility scenarios. S4 also
uses detector recall as a proxy for ANPR detection rate. The simulation's
ANPR reads are generated by a seeded simulator; it does not run the image
detector or OCR engine.

## Decision

Keep 0.55 as the configurable default for the current baseline and retain the
S9 sweep for sensitivity analysis. Do not treat the sweep or simulator results
as a threshold calibration for live camera data.

Calibrate the threshold using labelled, representative image reads and
evaluate the complete fusion and charging outcomes before changing the live
default.

## Consequences

- The existing fusion behavior has a stable default and can be tested across
  stricter acceptance thresholds.
- S9 can show how simulated identification and toll outcomes shift as the
  acceptance threshold changes.
- Since current OCR confidence values are heuristic, threshold comparisons
  are specific to this implementation and should not be generalized to other
  engines.
- Simulation results measure the modeled ANPR/RFID decision flow, not actual
  image-processing performance.

## Evidence and implementation

- `backend/app/config.py` sets the default `anpr_min_confidence` to 0.55.
- `backend/app/fusion/fusion_engine.py` applies the threshold before accepting
  an ANPR signal.
- `backend/app/simulation/scenarios.py` defines S9's threshold sweep and the
  S4 detection-rate proxy.
- `backend/app/anpr/simulator.py` generates synthetic ANPR outcomes for
  simulation runs.
- `backend/scripts/run_simulation.py` runs and exports the scenarios.

## Revisit when

The project has representative, labelled camera images and measured
end-to-end results for plate reads, incorrect associations, exceptions, and
latency.
